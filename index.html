About This Mod

KillLeader is a comprehensive utility for combat tracking and server administration. Key features include:

  • Combat Monitoring: Advanced event handling via CombatEvents and PlayerTickHandler.
  • Administration: Robust control through AdminCommands and GodModeManager.
  • Data & Metrics: Persistent tracking using KillDataManager[cite: 3].
  • Visuals: Real-time HUD rendering for combat stats.
